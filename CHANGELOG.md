Формат за [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/), версії за [SemVer](https://semver.org/lang/uk/).

- Робочий процес публікації: реліз на GitHub відправляє пакет у npm (з provenance) і реєструє версію в офіційному реєстрі MCP через OIDC.

## [0.2.0] - 2026-09-21

### Додано
- Пакет у npm: `horoshop-mcp-server`. Встановлення без Git і без збірки на стороні клієнта.
- Димовий тест `npm test`: піднімає сервер, перевіряє 118 інструментів, чистоту stdout і маршрутизацію по магазинах.
- CI на GitHub Actions: збірка, димовий тест і перевірка актуальності довідника на Node 18 і 22.
- `docs/tools.json` - машинний індекс інструментів для агентів; `docs/tools/*.md` - довідник посторінково.
- `AGENTS.md`, `llms.txt`, `server.json` - вхідні точки для ШІ-агентів і реєстру MCP.
- Сторінка проєкту на GitHub Pages з розміткою для пошуку та ШІ-відповідей.
- `SECURITY.md`, `CONTRIBUTING.md`, шаблони issue і пулл-реквестів.
- Схема архітектури і бейджі в README.

### Виправлено
- `horoshop_admin_login_check` більше не повертає живий `auth_token` сесії адмінки: значення маскується, як і решта секретів.

### Змінено
- Версія сервера в рукостисканні MCP береться з `package.json`, а не з константи в коді.

## [0.1.0] - 2026-09-13

Перший публічний випуск: 118 інструментів (публічний API Хорошопу, адмінка, кошик вітрини), кілька магазинів в одному сервері, документація українською, російською та англійською.
